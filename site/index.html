// OPERATING MODES

What it does

Three input modes, one shared pipeline under the hood.

01

IMAGE DETECT

Upload any image — objects come back bounded, labeled, and scored in a single pass.

02

VIDEO TRACK

Full videos processed frame-by-frame; ByteTrack keeps a stable ID on every object.

03

LIVE WEBCAM

Real-time detection and tracking streamed from your camera at interactive rates.

04

CONF / IOU

Confidence and IoU thresholds exposed as live dials — tune precision against recall.

// SIGNAL PATH

How it works

A letterboxed 640×640 tensor in, annotated coordinates out.

STAGE_01

PREPROCESS

Letterbox to 640×640, BGR→RGB, normalize, NCHW layout.

▸
STAGE_02

INFER

YOLO26 runs on ONNX Runtime — Python or C++ — emitting a (1,84,8400) tensor.

▸
STAGE_03

DECODE + NMS

Anchor-free decode and class-aware NMS distill boxes, scores, class IDs.

▸
STAGE_04

TRACK

IoU matching assigns persistent IDs; stale tracks age out after 30 misses.

▸
STAGE_05

ANNOTATE

Boxes, label pills, track IDs, and motion trails draw back onto the frame.

// FIRST BOOT

Quick start

Clone, install, run.

bash — visiontrack/ 
$ git clone https://github.com/Lush08/visiontrack.git
$ cd visiontrack
$ python -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt
# launch the interactive demo
$ cd python && python demo_gradio.py    # → localhost:7860
# or run a single image through the CLI
$ python python/demo_tracker.py --source test_bus.jpg --output result.jpg
